# Alejo Lovallo — Writing

Personal writing site migrated from [Medium](https://alejolovallo.medium.com), organized into lists:

- **Fonder / AI Treasury**
- **Blockchain / Crypto**
- **Reflections**

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

Posts live in `content/posts/` as Markdown/MDX with frontmatter (`title`, `date`, `list`, `excerpt`, `mediumUrl`). Lists are defined in `content/lists.json`.

Apple-inspired dark grey UI: clean typography, list browsing, and post pages with a link back to the Medium original.
